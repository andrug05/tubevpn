# RideTube

[English](https://github.com/JustAnotherPU/RideTube/blob/main/README.md) · [简体中文](README.zh-CN.md)

RideTube поддерживает английский, французский, нидерландский, немецкий, испанский, итальянский, португальский, русский и упрощённый китайский языки (выбираются в настройках). Перевод на китайский выполнен 小白151 (JackieZ123430). В [китайском руководстве](README.zh-CN.md) описаны установка, настройки воспроизведения и поддержка шрифтов.

> **Экспериментальное неофициальное приложение.** RideTube — неофициальный клиент YouTube. Он не связан с Google или YouTube, не одобрен и не спонсируется этими компаниями. Используйте его на свой страх и риск. Вы несёте ответственность за соблюдение Условий использования YouTube и законодательства своей страны, а также за безопасное использование приложения. По умолчанию изображение отображается только на стоящем автомобиле.

Скриншоты сделаны на компьютере с демонстрационными данными (названия фильмов из открытой библиотеки Blender), а не сфотографированы в автомобиле.

RideTube воспроизводит видео YouTube на головном устройстве BMW с iDrive 7 (MGU). Установка выполняется через MGU Store. Всё работает непосредственно в автомобиле, используя его собственное интернет-соединение:

- **Главная**, **Подписки**, **Посмотреть позже**, **История** и ваши **Плейлисты** доступны после входа в автомобиле через YouTube TV. Для авторизации нужно ввести код на телефоне; RideTube никогда не получает ваш пароль.
- Когда список видео заканчивается, через 5 секунд автоматически запускается первое рекомендованное видео. Кнопка Next на руле позволяет пропустить сегмент, видео или главу либо перейти к рекомендованному видео.
- Поиск, страницы каналов, главы, выбор качества видео и режим отображения Fit или Fill.
- Пропуск сегментов через [SponsorBlock](https://sponsor.ajay.app): спонсорские блоки, самореклама, вступления и другие подобные фрагменты.
- Звук воспроизводится через штатный медиаплеер автомобиля.
- Во время движения изображение заменяется режимом подкаста (название, прогресс и элементы управления), а звук продолжает воспроизводиться. Когда автомобиль останавливается, изображение появляется снова.
- Видео передаются потоково. Головное устройство загружает примерно 2 минуты видео вперёд, хранит этот фрагмент в оперативной памяти (не более нескольких десятков мегабайт) и удаляет уже просмотренные данные. Поэтому при остановке воспроизведения через пять минут расход трафика составляет примерно пять минут просмотра. При перемотке вперёд или назад воспроизведение обычно возобновляется через 1–2 секунды.
- Кнопка **Download** в проигрывателе сохраняет видео в автомобиле до его удаления (нажатием **Downloaded**). Загруженные видео можно смотреть без интернета через раздел **Library** на боковой панели или **On this car** на главном экране. Авторизация не требуется. Одновременно загружается только одно видео; загрузка не выполняется во время воспроизведения, а на головном устройстве должно быть не менее 4 ГБ свободного места.
- Настройка автоматической загрузки позволяет скачивать 3, 5 или 10 последних видео из подписок. Функция работает только через Wi-Fi и при выполненном входе в аккаунт. По умолчанию она выключена. После просмотра такие видео удаляются.
- После авторизации просмотренные видео добавляются в историю YouTube так же, как при использовании телевизора.
- **Send logs to the developer** (в меню приложения и на экране ошибки при сбое видео) отправляет разработчику последний журнал работы RideTube и результат проверки состояния системы. Перед отправкой требуется подтверждение. Из журналов удаляются данные аккаунта и сведения о просмотренных видео. Строки проверки состояния не содержат IP- и MAC-адресов, идентификаторов и названий видео. После отправки вы получаете короткий код для добавления в обращение на GitHub. Без подтверждения ничего не отправляется.
- **Health check** в меню проверяет работу сервиса и его инструментов, интернет-соединение, свободное место и аудиосервис автомобиля. Результат отображается отдельной строкой для каждой проверки.

## Требования

- Автомобиль BMW с iDrive 7 (MGU, \`ID7\`) и установленным [MGU Store](https://github.com/robertnisipeanu/mgu-store).
- Подключение автомобиля к интернету через uplink Store (\`mgu-uplink\`).
- Необходимые зависимости устанавливаются через MGU Store. Сохраните их источники в Store:
  - Из собственного источника Store: рендерер \`mgu-render\` версии 0.6.11 или новее, \`mgu-deploy\` 0.7.0 и \`mgu-python\` 1.0.2.
  - Из стандартного источника Store \`cauliflowermossgrape/idrive7-apps\`: контроллер ввода \`mgu-inputgate\` 1.0.0.

## Установка

В MGU Store добавьте источник:

\`\`\`
JustAnotherPU/ridetube
\`\`\`

Когда Store спросит, за какой веткой следить, выберите **Releases**. Указывайте только \`owner/repo\`: Store не принимает суффикс \`:releases\` в конце.

Затем установите RideTube. Вместе с приложением Store устанавливает его сервис (\`jap-ridetube-d\`, включающий проигрыватель, загрузчик yt-dlp и декодер видео) и \`jap-node22\` — Node.js 22, необходимый для работы сервиса. Начиная с версии 0.4.0, этот источник также содержит сам \`jap-node22\` (тот же файл публикуется в \`JustAnotherPU/mgu-apps\`), поэтому добавлять источник mgu-apps больше не требуется.

**Дополнительно для iDrive 7:** инструмент Full-width touch (\`mgu-render-id7-touch\`) из этого источника позволяет RideTube использовать полосу у левого края экрана, где обычно находится кнопка возврата автомобиля. Это расширяет боковую панель и плитки. Без этого инструмента RideTube не использует данную область. В Health check можно посмотреть, какой вариант установлен.

## Настройки

- **Language (Язык):** Auto (автоматически использует язык автомобиля, если RideTube его поддерживает, иначе — английский), English, Français, Nederlands, Deutsch, Español, Italiano, Português, Русский или 中文. Язык YouTube и страна соответствуют настройкам языка iDrive (при выборе Auto язык определяется автоматически; страна учитывается всегда), поэтому лента и результаты поиска соответствуют настройкам автомобиля.
- **Video while driving (Видео во время движения):** по умолчанию выключено. Не включайте эту функцию, если автомобиль не закодирован для воспроизведения видео в движении и экран не предназначен исключительно для пассажиров. При включении сначала отображается предупреждение; настройка активируется только после нажатия I agree. Кнопка Cancel отменяет включение. Вы используете функцию на свой страх и риск: авторы RideTube не несут ответственности за неправильное использование, аварии, штрафы или повреждения. Настройка начинает действовать только после включения на стоящем автомобиле. Если включить её во время движения, изображение останется скрытым до следующей остановки.
- **Fill the screen (Заполнить экран):** по умолчанию выключено (чёрные полосы по краям); при включении изображение обрезается, чтобы заполнить экран.
- **Video quality (Качество видео):** Auto (720p при подключении к Wi-Fi, 480p при использовании мобильного интернета), 720p, 480p или 360p.
- **Show members-only videos (Показывать видео только для участников):** по умолчанию выключено. Канал также можно скрыть непосредственно на его странице.
- **Show Shorts (Показывать Shorts):** по умолчанию выключено.
- **SponsorBlock:** для каждой категории можно выбрать автоматический пропуск, отображение кнопки Skip или отключение.
- **Parked: pause when the 12 V battery is under (На стоянке: приостанавливать воспроизведение, если заряд 12-вольтовой батареи ниже):** 60, 65 (по умолчанию), 70 % или никогда.
- **Sign in / Sign out:** вход и выход из аккаунта в меню приложения.

Проверка стоянки использует показания скорости автомобиля. Если показания старше 5 секунд, автомобиль считается движущимся.

## Известные ограничения

- **yt-dlp периодически перестаёт работать после изменений на стороне YouTube.** При включённой настройке "Update yt-dlp by itself" (по умолчанию) сервис ежедневно и после каждой неудачной попытки воспроизведения загружает на автомобиль последнюю версию yt-dlp, проверяя её по SHA256-суммам релиза. Если настройка выключена, новая версия yt-dlp поставляется вместе с обновлением RideTube (см. \`native/jap-ridetube-d/README.md\`, раздел "Updating yt-dlp").
- Поддерживаются H.264 или VP9 (Profile 0), предпочтительно до 720p при 30 кадрах в секунду. Декодирование выполняется графическим процессором головного устройства. Видео, доступные только в других форматах (AV1, HDR), не воспроизводятся.
- Для входа используется механизм авторизации YouTube TV, применяемый в телевизионных приложениях YouTube. Client ID считывается со страницы YouTube TV во время входа; RideTube не содержит собственного Client ID.
- При переключении с первых секунд звука на полный файл может быть слышен короткий перерыв.
- **Неправильные дата и время головного устройства.** Если дата головного устройства раньше даты выпуска этой версии приложения, часы заведомо настроены неправильно. В этом случае RideTube пропускает одну проверку TLS — проверку срока действия сертификата, чтобы видео продолжало воспроизводиться. Сертификат по-прежнему должен быть выдан доверенным центром сертификации и соответствовать имени нужного хоста. Приложение один раз предупреждает об этом, а в меню отображается "Wrong clock", пока дата и время автомобиля не будут исправлены. Риск: злоумышленник, у которого есть старый просроченный сертификат YouTube или другого используемого RideTube хоста вместе с закрытым ключом и возможность перехватить трафик автомобиля, может выдать себя за этот хост. При неправильных часах миниатюры не отображаются. Подробнее: \`native/jap-ridetube-d/README.md\`, раздел "Security notes".
- **Сервис RideTube работает с правами root.** Управляющий сокет доступен только пользователю приложения RideTube. Если после новой установки сервис не может определить пользователя приложения, сокет временно доступен всем приложениям, пока пользователь не будет определён. Подробнее: \`native/jap-ridetube-d/README.md\`, раздел "Security notes".

## Удаление

1. В RideTube выполните **Sign out** (или позднее отзовите разрешение "YouTube on TV" на странице https://myaccount.google.com/permissions). Удаление приложения стирает данные входа из автомобиля, но Google сохраняет выданное разрешение до его отдельного отзыва.
2. В MGU Store удалите **RideTube**, а затем его сервис \`jap-ridetube-d\`. Если обновление оказалось неудачным, его можно отменить через Store, пока предыдущая версия ещё сохранена.

## Сборка и тестирование на компьютере

\`\`\`sh
node kit/tools/test_runtime.js && node kit/tools/test_life.js && node kit/tools/test_parked.js \\
  && node kit/tools/test_qr.js
(cd native/jap-ridetube-d && node test/test_ytd.js && node test/test_thumb.js && python3.12 -I test/test_ytfetch.py)
(cd native/ytdec && make test && make target)     # make target требует Docker
node tools/test_sequences.js --seed 1     # проверка последовательностей команд сервиса (остановка, качество, пауза, перемотка во время запуска)
tools/check_node8.sh     # в автомобиле ytd.js и приложение работают на Node 8: node --check в образе node:8 (Docker)
\`\`\`

Для выпуска релиза требуется папка \`oap-sdk\`, извлечённая из принадлежащего вам приложения BMW (\`node kit/tools/extract_sdk.js <javascript/app.js приложения BMW>\`; никогда не добавляйте её в репозиторий).

Затем выполните:

\`\`\`sh
python3 kit/tools/build.py jap_ridetube && node kit/tools/test_ridetube.js
export MGU_STORE=<клон репозитория MGU Store>
(cd native/jap-ridetube-d && ./build.sh)      # jap-node22 собирается в github.com/JustAnotherPU/mgu-apps
python3 tools/release.py      # dist/release/: все файлы нужно загрузить в GitHub Release с тегом "catalog"; jap-node22 из mgu-apps закреплён по SHA256
\`\`\`

Для тестов требуются Node.js 18 или новее, Python 3.12 и ffmpeg.

## Переводы

Меню приложения доступно на английском, французском, нидерландском, немецком, испанском, итальянском, португальском, русском и упрощённом китайском языках. Pull request с новыми переводами приветствуются. Если вы не хотите делать перевод самостоятельно, создайте Issue и укажите нужный язык.

Чтобы добавить новый язык:

1. Скопируйте \`kit/runtime/locales/fr.json\` в \`kit/runtime/locales/<code>.json\`, где \`<code>\` — двухбуквенный код языка (\`sv\` для шведского, \`pl\` для польского). Сохраните ключи (это английские тексты) и переведите значения.
2. Не изменяйте конструкции \`{placeholder}\`. Ключ, содержащий \`|\`, обозначает множественное число: укажите формы единственного и множественного числа через \`|\`.
3. Названия пунктов боковой панели (Home, Subs, Later, Playlists, History) должны быть короткими: для каждого доступно около 90 пикселей.
4. Добавьте язык в настройку Language в \`apps/jap_ridetube/app.json\`: укажите код и название на самом языке (например, \`["sv", "Svenska"]\`).
5. Запустите \`node kit/tools/test_runtime.js\`. Скрипт проверяет наличие всех строк, соответствие плейсхолдеров и наличие всех необходимых символов в шрифтах.

Режим Auto и меню автомобиля автоматически подхватят новый язык. Языки, которым требуется более двух форм множественного числа или символы за пределами используемых латинских шрифтов, потребуют дополнительных изменений в коде. Укажите это в pull request — автор поможет.
